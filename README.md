# ExcitebikeTrabalhoDevGame
## Características gerais
**Valor**: 30 pontos

**Datas de entrega**: Até 18/10/2026

**Grupo**: Individual ou em dupla

**Objetivo**: Desenvolver um protótipo de um dos jogos listados abaixo, utilizando a Godot, buscando replicar as mecânicas do jogo com o máximo de fidelidade possível.

**Descrição**
A ideia deste trabalho é que o(s) aluno(s) possa(m) desenvolver um pequeno protótipo de algum jogo conhecido. Para cada aluno ou grupo, será atribuído aleatoriamente um jogo de uma lista pré-definida. O objetivo é tentar replicar as características do jogo original. Naturalmente, é permitido o uso de sua criatividade para fazer modificações no jogo original, desde que a essência do mesmo seja mantida. Cada aluno deverá se preocupar em construir apenas um protótipo funcional que ilustre as mecânicas básicas de jogo, conforme lista de itens de implementação definida para cada jogo. Não há necessidade de fases adicionais ou variação em níveis de dificuldade, a menos que especificado em contrário. Áudio e elementos de interface também são opcionais, a menos que especificado em contrário. Em caso de dúvida a respeito de um jogo específico, consulte o professor. Os assets a serem utilizados devem estar disponíveis para uso gratuito na Internet, ou terem sido criados pelo próprio aluno.
## Entrega
Um representante (e apenas um) do grupo deverá submeter, via Google Classroom, um link para o repositório do jogo no GitHub. Dentro do repositório deve haver uma pasta “build”, contendo um executável do jogo para Linux. Teste o executável antes da submissão. Certifique-se também de deixar o repositório público para que o acesso possa ser realizado.
## Avaliação
O aluno será avaliado quanto à adequação da sua implementação ao jogo original. A fidelidade aos elementos gráficos de cada jogo não será exigida, uma vez que o aluno pode não conseguir encontrar ou replicar com precisão esses elementos, e em alguns casos pode não ter os direitos autorais para uso dos mesmos. Os critérios utilizados serão:
  1. Replicação adequada das mecânicas do jogo original;
  2. Atendimento aos itens de implementação especificados;
  3. Execução correta do projeto;
  4. Qualidade do código apresentado;
  5. Entrega dentro do prazo (desconto de 5% por dia de atraso);
  6. *Apresentação em sala de aula*.

*Obs.*: Qualquer identificação de plágio ou de não-autoria do código desenvolvido resultará em nota 0.
